TrustLens AI

AI-Based Multilingual Scam Detection & Digital Fraud Awareness Platform

TrustLens AI is a web-based platform designed to help users identify suspicious scam messages and potentially fraudulent links. The system uses machine learning, OCR and multilingual text processing to provide understandable scam detection results and safety recommendations.

Features

- AI-based scam message detection
- Scam probability and risk level
- Explainable detection with warning reasons
- English, Hindi and Marathi support
- Screenshot/OCR-based scam detection
- Suspicious link detection
- Scam reporting
- Digital fraud awareness and safety tips

Technology Stack

- Python
- Flask
- HTML, CSS and JavaScript
- Scikit-learn
- TF-IDF and Logistic Regression
- Tesseract OCR
- Deep Translator
- SQLite

How It Works

1. User enters a suspicious message, uploads a screenshot or enters a link.
2. The system processes the input.
3. The AI model analyzes suspicious messages.
4. OCR extracts text from uploaded screenshots.
5. The link detector checks suspicious URL characteristics.
6. The system provides a risk level, probability, reasons and safety recommendations.
